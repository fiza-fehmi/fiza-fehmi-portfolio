# Project Images

Place your project screenshot images in this folder with the following names:

- `ecommerce.jpg` - MERN E-Commerce Platform screenshot
- `property.jpg` - Property Management System screenshot  
- `taskmanager.jpg` - Task Management Application screenshot
- `business.jpg` - Full-Stack Business Website screenshot
- `portfolio.jpg` - Modern Portfolio Website screenshot
- `ai-app.jpg` - AI-Powered Web Application screenshot

## Recommended Image Specifications

- **Aspect Ratio**: 4:3 or 16:10
- **Resolution**: At least 1200x900px
- **Format**: JPG or PNG
- **File Size**: Optimize to under 500KB for better performance

## Temporary Placeholders

The portfolio currently uses gradient placeholders with project numbers. Replace these images to see your actual project screenshots.
